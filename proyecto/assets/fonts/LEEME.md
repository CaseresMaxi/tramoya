# Fuentes

- `playfair-latin.woff2`, `playfair-latin-italic.woff2`: Playfair Display (Claus Eggers Sørensen), variable 400–900.
- `inter-latin.woff2`: Inter (Rasmus Andersson), variable 100–900.

Las dos se distribuyen con la SIL Open Font License 1.1: se pueden usar, incluir y
redistribuir libremente (no se pueden vender solas). Son subconjuntos latinos.

Para usar otra fuente: copiala acá en `.woff2`, declarala en `fuentes` y `tipografia` de
`proyecto/proyecto.js` y, si es la de la marca, corré `python3 herramientas/generar_glifos.py`.
