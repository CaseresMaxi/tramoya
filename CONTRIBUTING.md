# Aportar a Tramoya

¡Gracias! Antes de mandar un pull request:

- Tramoya se distribuye bajo [PolyForm Noncommercial 1.0.0](LICENSE.md) y además se
  ofrece con [licencia comercial](COMERCIAL.md). Para poder seguir haciéndolo, **al mandar
  un aporte aceptás que el autor (CaseresMaxi) pueda distribuirlo bajo esas dos licencias**
  (y bajo las que las reemplacen), y declarás que el aporte es tuyo o que tenés derecho a
  hacerlo. Si no estás de acuerdo, no lo mandes.
- Leé `CLAUDE.md` (cómo está armado y cómo se prueba) y mirá el resultado en un navegador
  real antes de proponer un cambio (`node scripts/tramoya.mjs revisar …`).
